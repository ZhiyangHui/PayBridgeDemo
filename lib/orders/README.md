# 订单 / Orders

改商品看 `catalog.ts`，改模拟订单和余额看 `service.ts`，改平台订单看 `remote.ts`、`sandbox.ts`，查历史订单看 `history.ts`。金额统一按分计算。

Edit `catalog.ts` for products, `service.ts` for mock orders and balances, `remote.ts` and `sandbox.ts` for provider orders, and `history.ts` for order lists. Amounts are stored in integer fen.
