# 共用组件 / Shared components

`PageShell` 管页面外壳，`AccountNav` 放导航，`UserAvatar` 显示头像，`FormMessage` 显示错误，`OrderPoller` 更新订单状态。

`PageShell` provides the page frame, `AccountNav` navigation, `UserAvatar` avatars, `FormMessage` errors, and `OrderPoller` status updates.

`LanguageProvider` 提供语言切换，`PageShell` 显示公共页头。

`LanguageProvider` handles language switching; `PageShell` renders the shared header.
